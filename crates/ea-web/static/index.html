Proyectos

Cómo funciona

  1. Claude Code formaliza. Con /mision, /obra o /rutina deja una orden en la cola del modelo local. Esta página no lanza trabajo nuevo, salvo las rutinas.
  2. El modelo local ejecuta. El orquestador toma la orden, trabaja en el worktree (con su semáforo) y entrega un informe.
  3. Claude Code revisa. Cierra el trabajo, lo reformula con una nota o, en una obra, lo deja continuar. Tú también puedes hacerlo desde la ficha.
  4. Tú decides lo que falla. Si una rutina falla, su paquete de corrección queda en espera hasta que lo confirmes (con contexto si quieres).

La escena

Arriba de la portada, cada agente es una máquina de gashapon y cada trabajo una cápsula. La pila que se ve tras el cristal es su cola; el semáforo dice quién tiene el worktree; el raíl de arriba es el orquestador, que mueve las cápsulas. Pulsa una cápsula para abrir su ficha; ▶ demo enseña un recorrido de ejemplo sin tocar nada.

cápsula
la mitad de arriba es el modo: roja misión, azul obra, amarilla rutina, rosa propuesta (con rombo). Gira si se ejecuta, lleva halo si espera, se apaga al cerrarse
placa
el nombre de cada agente, como en la tapa de su máquina; la pegatina azul COLA dice cuántas cápsulas esperan
★
el premio: el informe que trae un trabajo
! aviso
la máquina se sacude y avisa: paquete de corrección, trabajo bloqueado, orquestador sin latido o servicio parado

Botones

Cada botón lleva el gesto de la máquina y, en gris, la acción real; el título da la explicación completa. El azul redondo es la acción principal de la fila; en rojo, cuando decide algo que falló.

▶ echar ficha
lanzar una rutina: lo único que crea trabajo aquí
★ canjear
cerrar: el premio (el informe) vale
▶ seguir girando
continuar una obra con las fases que quedan
↺ volver a girar
reformular, con nota obligatoria
⊘ devolver
cancelar; segundo clic para confirmar
✓ desatascar
confirmar un paquete de corrección: pasa a Claude Code
✓ aceptar
decidir una propuesta; las irreversibles, solo en terminal

Estados de un trabajo

○ en cola
orden creada; espera al modelo local
◐ ejecutando
el modelo local trabaja en el worktree
◇ en revisión
entregado; espera a Claude Code (cerrar, reformular o continuar)
! en espera
paquete de corrección de una rutina que falló; espera tu confirmación
● cerrado
revisado y dado por bueno
⊘ cancelado
descartado antes de cerrarse

Secciones

⌂ Inicio
la escena de los agentes, colas, semáforo del worktree y tablero de trabajos
▤ Trabajos
misiones, obras y rutinas; ficha con informe, diff y acciones
≡ Diario
el registro de cada cosa que ocurre
↻ Rutinas
las rutinas registradas, con su versión; se pueden lanzar
◇ Propuestas
cambios que esperan tu visto bueno
▶ Acciones
herramientas: simular y ejecutar a mano
▦ Sistema
servicios y agentes; reiniciar un servicio
▥ Bóveda
las notas, con buscador
✎ Memoria
la memoria de Claude Code de cada proyecto; se lee renderizada y se edita
